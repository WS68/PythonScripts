# Набор скриптов Python для обработки данных с помощью ИИ

Репозиторий содержит полезные скрипты на Python для различных задач обработки данных с использованием искусственного интеллекта.

## Содержание

Каждый скрипт решает отдельную практическую задачу обработки данных с использованием искусственного интеллекта. Для каждого скрипта здесь будут доступны:

- краткое описание и область применения;
- требования для запуска;
- параметры и примеры использования;
- форматы входных и выходных данных;
- ограничения и известные особенности.

## `random_names.py`

Скрипт генерирует случайные русские фамилии и выбирает имя с отчеством из
фиксированных списков. Для каждой записи сначала случайно выбирается пол, затем
независимо выполняются все необходимые случайные выборы. Благодаря этому форма
фамилии, имя и отчество согласованы по полу.

### Запуск

Скрипт рассчитан на Windows и использует только стандартную библиотеку Python:

```text
python random_names.py
python random_names.py 20 --format IF --output people.txt
python random_names.py 5 --format OIF --output "C:\temp\names.txt"
```

Аргументы и параметры:

- `N` — количество записей, позиционный аргумент; по умолчанию `10`. Значение
  должно быть положительным целым числом.
- `--format` — порядок частей имени; по умолчанию `FIO`.
- `--output` — путь к выходному файлу; по умолчанию `names.txt`.

В формате используются латинские буквы без учета регистра:

- `F` — фамилия;
- `I` — имя;
- `O` — отчество.

Каждая буква может встретиться не более одного раза. Например, `IF` выводит
сначала имя, а затем фамилию; `I` выводит только имя. Пустой формат и символы,
отличные от `F`, `I`, `O`, запрещены.

### Алгоритм фамилии

Фамилия строится из случайно выбранного первого шаблона (`СГ`, `ССГ`,
`СГСГ`, `СГСГСГ` или `ССГСГ`), случайно выбранного предпоследнего шаблона
(`ССГС` или `СГС`) и случайного окончания. Для мужского варианта используются
`-ов` и `-ин`, для женского — `-ова` и `-ина`. Первая буква готовой фамилии
делается заглавной.

В шаблонах `С` означает согласную, а `Г` — гласную. Каждая буква выбирается
с весом, соответствующим её распространенности в русском языке, поэтому
редкие буквы вроде `ж`, `ц` и `щ` встречаются реже распространенных. Используются
только обычные русские буквы; `ъ`, `ь`, `ё`, `й` и `ы` не используются.
Одинаковые согласные непосредственно рядом не допускаются, в том числе на
границе частей фамилии. Одинаковые согласные, разделенные гласной, допустимы.

Имя и отчество выбираются случайно из отдельных фиксированных списков мужских
и женских вариантов. Списки содержат распространенные русские имена и
соответствующие формы отчеств, но не являются полным справочником.

### Результат

В файл записывается одна запись в строке в порядке, указанном в `--format`.
Файл создается в кодировке UTF-8 без BOM. Информационные и ошибочные сообщения
скрипта выводятся на английском языке, чтобы не смешивать их с русскими данными.
